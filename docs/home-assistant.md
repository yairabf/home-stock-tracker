# Home Assistant integration

<img src="https://brands.home-assistant.io/_/homeassistant/icon.png" alt="Home Assistant icon" width="56">

The Home Assistant integration is now maintained in its dedicated repository:
[Home Stock Tracker HA](https://github.com/yairabf/home-stock-tracker-ha).

Install it as a HACS custom integration and use that repository for current
setup, entity, troubleshooting, and release documentation. The integration is
read-only: it exposes grocery, inventory, and low-stock data without changing
Home Stock Tracker household state.
