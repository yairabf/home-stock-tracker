# Home Stock Tracker

Track your home inventory and stock levels.

## Getting Started

This project is in early development and uses NestJS.

## Commands

- Development server: `npm run start:dev`
- Build: `npm run build`
- Production server: `npm run start:prod`
- Lint: `npm run lint`
- Tests: `npm run test`
- End-to-end tests: `npm run test:e2e`
