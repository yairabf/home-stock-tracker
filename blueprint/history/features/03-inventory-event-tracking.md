# Feature 3: Inventory event tracking

**Status:** complete

**Goal:** Record structured household stock signals (restocked, low, out, still available) as immutable events, establishing the append-only source of truth for all downstream consumption estimation and prediction.

---

## Scope

### In scope

- New Prisma model: `InventoryEvent` with enum `InventoryEventType`
- New module: `inventory` with controller, service, DTOs
- REST API endpoints to record and query inventory events
- `InventoryEventType` covers: `GROCERY_ADDED`, `GROCERY_REMOVED`, `PURCHASED`, `RESTOCKED`, `STOCK_LOW`, `STOCK_OUT`, `STOCK_CONFIRMED`, `STOCK_CORRECTED`, `PREDICTION_ACCEPTED`, `PREDICTION_REJECTED`, `INFERRED_LOW_STOCK`
- Record events with productId, eventType, optional quantity/unit, source, optional confidence, optional metadata
- Timestamp auto-generated on creation
- Query events by productId and/or eventType with pagination
- Unit and integration tests for the event recording flow

### Out of scope

- Derived statistics or aggregation (feature 7)
- Prediction engine or low-stock logic (features 6 and 9)
- Purchase flow that relates grocery list items to purchase events (feature 4)
- Household profile integration (feature 5)
- Authentication/authorization (feature 16)
- MCP tool exposure (feature 12)

## Data model and contracts

### InventoryEventType (enum)

```
GROCERY_ADDED
GROCERY_REMOVED
PURCHASED
RESTOCKED
STOCK_LOW
STOCK_OUT
STOCK_CONFIRMED
STOCK_CORRECTED
PREDICTION_ACCEPTED
PREDICTION_REJECTED
INFERRED_LOW_STOCK
```

### InventoryEvent (model)

- `id` (String, UUID) - primary key, auto-generated
- `productId` (String, FK -> Product.id) - required, validates product exists
- `eventType` (InventoryEventType) - required
- `quantity` (Float, optional)
- `unit` (String, optional)
- `timestamp` (DateTime) - auto-generated on creation
- `source` (String) - required, e.g. "hermes_whatsapp", "api"
- `confidence` (Float, optional) - 0.0 to 1.0 for inferred events
- `metadata` (Json, optional)

### API contracts

**POST /api/v1/inventory/events**

Request:
```json
{
  "productId": "uuid",
  "eventType": "STOCK_LOW",
  "quantity": 1,
  "unit": "liter",
  "source": "hermes_whatsapp",
  "confidence": 0.8,
  "metadata": { "note": "user mentioned they might be low" }
}
```

Response (201):
```json
{
  "id": "uuid",
  "productId": "uuid",
  "eventType": "STOCK_LOW",
  "quantity": 1,
  "unit": "liter",
  "timestamp": "2026-08-26T10:00:00.000Z",
  "source": "hermes_whatsapp",
  "confidence": 0.8,
  "metadata": { "note": "user mentioned they might be low" }
}
```

**GET /api/v1/inventory/events?productId=uuid&eventType=STOCK_LOW&limit=20&offset=0**

Response (200):
```json
{
  "items": [ ... ],
  "total": 42,
  "limit": 20,
  "offset": 0
}
```
